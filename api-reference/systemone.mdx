# Multi-Question Fan-Out (`POST /v1/systemone`)

Evaluates multiple distinct visual questions against an image in a **single forward pass**.

### Architecture: Single Image Embedding, Parallel Projections

In autoregressive models (VLMs), answering 5 questions requires running 5 independent token generation passes or concatenating large prompts that compete for attention. 

ImageJev embeds the image **once** into vector space ($D=512$ or $768$). All question criteria vectors are then multiplied against this single embedding simultaneously. Evaluating 10 questions takes virtually the same GPU time (~15ms) as evaluating 1.

<Note>
This endpoint is also accessible via the alias `POST /v1/decide`.
</Note>

---

## Request

### Headers

| Header | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `Content-Type` | `string` | **Yes** | Must be `application/json`. |
| `X-API-Key` | `string` | Conditional | Required when operating in `production` or `staging` environments. |

### Body Parameters

| Parameter | Type | Required | Constraints | Description |
| :--- | :--- | :--- | :--- | :--- |
| `image` | `string` | **Yes** | Max 10MB | Public image URL (`https://...`), Base64 string, or data URI. |
| `questions` | `object` | **Yes** | 1 to 25 questions | Dictionary mapping unique string identifiers to question definitions. |

Each entry in `questions` must contain:
- `decision` (`string`): The plain-language prompt or question.
- `schema` (`object`): Choice, Score, or Noul definition.

## Code Examples

<CodeGroup>
```bash cURL
curl -X POST "https://api.imagejev.dev/v1/systemone" \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "image": "https://images.unsplash.com/photo-1542291026-7eec264c27ff",
    "questions": {
      "item_category": {
        "decision": "Identify the primary merchandise category",
        "schema": {
          "type": "choice",
          "options": {
            "footwear": "shoes, sneakers, boots, or sandals",
            "apparel": "shirts, pants, jackets, or clothing",
            "accessories": "jewelry, hats, bags, or belts"
          }
        }
      },
      "lighting_quality": {
        "decision": "Rate studio lighting quality",
        "schema": {
          "type": "score",
          "levels": [
            "dark or underexposed",
            "uneven harsh shadows",
            "clear ambient lighting",
            "flawless studio balanced exposure"
          ]
        }
      },
      "has_watermark": {
        "decision": "Is there a watermark or copyright text overlay?",
        "schema": {
          "type": "noul",
          "true": "visible translucent watermark, logo stamp, or copyright text",
          "false": "clean photo with no watermark or text stamps"
        }
      }
    }
  }'
```

```python Python (SDK)
from imagejev import ImageJevClient

client = ImageJevClient(base_url="https://api.imagejev.dev", api_key="YOUR_API_KEY")

result = client.decide_multi(
    image="https://images.unsplash.com/photo-1542291026-7eec264c27ff",
    questions={
        "item_category": {
            "decision": "Identify the primary merchandise category",
            "schema": {
                "type": "choice",
                "options": {
                    "footwear": "shoes, sneakers, boots, or sandals",
                    "apparel": "shirts, pants, jackets, or clothing",
                    "accessories": "jewelry, hats, bags, or belts"
                }
            }
        },
        "lighting_quality": {
            "decision": "Rate studio lighting quality",
            "schema": {
                "type": "score",
                "levels": [
                    "dark or underexposed",
                    "uneven harsh shadows",
                    "clear ambient lighting",
                    "flawless studio balanced exposure"
                ]
            }
        },
        "has_watermark": {
            "decision": "Is there a watermark or copyright text overlay?",
            "schema": {
                "type": "noul",
                "true": "visible translucent watermark, logo stamp, or copyright text",
                "false": "clean photo with no watermark or text stamps"
            }
        }
    }
)

print(result["item_category"].choice)         # -> "footwear"
print(result["lighting_quality"].score)       # -> 3.84
print(result["has_watermark"].probability)    # -> 0.012 (no watermark)
```

## Constraints

- **Maximum question count**: `25` questions per request. Exceeding 25 questions returns `HTTP 400 Bad Request`.
