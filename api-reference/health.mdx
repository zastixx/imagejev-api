# Health & Metrics (`GET /health`)

Returns the operational status, version, real-time concurrency saturation, and configured resource limits of the ImageJev inference service.

<Note>
This endpoint is unauthenticated by design and can be polled freely by infrastructure orchestrators (e.g., Kubernetes liveness/readiness probes, AWS ALB target group health checks, Render, or Datadog synthetic monitors).
</Note>

## Request

```http
GET /health HTTP/1.1
Host: api.imagejev.dev
Accept: application/json
```

No query parameters or authentication headers are required.

---

## Code Examples

<CodeGroup>
```bash cURL
curl -X GET "https://api.imagejev.dev/health"
```

```python Python
import requests

resp = requests.get("https://api.imagejev.dev/health")
data = resp.json()

print(f"Status: {data['status']}")
print(f"Active in-flight requests: {data['concurrency']['in_flight']} / {data['concurrency']['max_concurrent']}")
```

```typescript TypeScript / Fetch
const response = await fetch("https://api.imagejev.dev/health");
const health = await response.json();
console.log(health.status, health.limits);
```
</CodeGroup>

## Response (`200 OK`)

```json
{
  "status": "ok",
  "service": "imagejev",
  "version": "0.2.0",
  "concurrency": {
    "in_flight": 1,
    "max_concurrent": 4
  },
  "rate_limiter": {
    "enabled": true,
    "default_rpm": 60
  },
  "limits": {
    "max_batch_size": 50,
    "max_questions": 25,
    "max_image_mb": 10
  }
}
```

### Response Schema

| Field | Type | Description |
| :--- | :--- | :--- |
| `status` | `string` | `"ok"` indicates the engine is ready to accept queries. |
| `service` | `string` | Service identifier (`"imagejev"`). |
| `version` | `string` | Running API server semantic version. |
| `concurrency.in_flight` | `integer` | Number of requests currently executing inside the inference lock. |
| `concurrency.max_concurrent` | `integer` | Maximum concurrent requests allowed before queueing or 503 rejection. |
| `rate_limiter.enabled` | `boolean` | Whether per-client rate limiting is active. |
| `rate_limiter.default_rpm` | `integer` | Standard requests per minute allocation per client. |
| `limits.max_batch_size` | `integer` | Maximum permitted images in a single `/decide_batch` call. |
| `limits.max_questions` | `integer` | Maximum permitted questions in a single `/v1/systemone` call. |
| `limits.max_image_mb` | `integer` | Maximum payload size in megabytes for binary and Base64 uploads. |
