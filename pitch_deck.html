How ImageJev Works
  • 01. Frozen Vision Backbone: Encodes images into normalized 512D hyperspherical embeddings once (ViT-B-32 / LAION-2B).

🛡️ ZERO-HALLUCINATION ROBUSTNESS

Solving the Out-of-Distribution Boundary

How ImageJev solves the closed-world assumption using Universal Null Prototypes and Absolute Semantic Relevance Gating.

The Out-of-Distribution Problem

Traditional closed-set softmax forces irrelevant images (e.g., asking {"cat", "dog"} on a sports car) into a false positive (99.9% cat) because probabilities must sum to 1.0.

ImageJev Dual-Gate Solution:
  • ✅ Universal Null Anchor: Injects background visual prior prototype into denominator.
  • ✅ Relevance Threshold (τ = 0.20): Rejects low cosine similarity inputs automatically.
