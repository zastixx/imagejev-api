# Visual decisions your code can use

ImageJev helps software make focused decisions about images. Provide an image, a question, and the answers your workflow accepts. The SDK returns a structured result your code can inspect, store, or route for review.

It is designed for focused visual checks such as:

- Is this product photo suitable for a listing?
- Which category best describes this image?
- How clear or complete is this upload?
- Should this item be sent to review?

## Three decision types

| Type | Use it for | Returns |
| :--- | :--- | :--- |
| [Choice](/primitives/choice) | Select one option from a defined list | `choice`, `probabilities`, `confidence` |
| [Score](/primitives/score) | Rate an image against ordered levels | `score`, `probabilities`, `confidence`, `dispersion` |
| [Noul](/primitives/noul) | Check one visual statement | `probability` |

## Keep questions focused

Use one clear question at a time. If a workflow depends on several independent checks, ask them separately and combine the results in your own application logic.

## Important limitations

Structured output does not guarantee a correct prediction. A defined list of options can still produce a confident but incorrect result when an image is unclear or outside the question. Include an explicit `other` option or use `allow_none` when out-of-scope images are possible, and validate thresholds on data from your task.

The interactive demo on the product website is illustrative and does not call a live inference service.
