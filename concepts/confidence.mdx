# Mathematical Confidence

Every `choice` and `score` evaluation in ImageJev yields a `confidence` metric normalized between `0.0` and `1.0`.

## How Confidence is Computed

For an evaluation with $K$ options and softmax probability vector $P = [p_1, p_2, \dots, p_K]$:

1. **Shannon Entropy**:
   $$H(P) = -\sum_{i=1}^K p_i \ln(p_i)$$

2. **Normalized Entropy**:
   $$H_{\text{norm}}(P) = \frac{H(P)}{\ln(K)}$$

3. **Confidence**:
   $$\text{confidence} = 1 - H_{\text{norm}}(P)$$

When one option dominates completely ($p_1 \approx 1.0$), $H(P) \to 0$ and `confidence` approaches `1.0`.
When all options are equally likely ($p_i = 1/K$), $H(P) = \ln(K)$ and `confidence` drops to `0.0`.

## Architecture Application: The Confidence Gate

Use confidence as an architectural threshold:

```python
result = jev.decide(image=img, decision=query, schema=schema)

if result.confidence >= 0.80:
    # High certainty: execute automated action
    handle_decision(result.choice)
else:
    # Low certainty: route to human review queue or fallback VLM
    route_to_fallback(img, query)
```
