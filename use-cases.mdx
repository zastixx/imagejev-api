# Example use cases

ImageJev works best as a focused decision step inside a larger workflow. Keep the question clear, define the outcomes your application can handle, and send uncertain cases for review.

<CardGroup cols={2}>
  <Card title="Catalog photo checks" icon="cart-shopping">
    Check focus, lighting, background, or listing suitability before publishing an item.
  </Card>
  <Card title="Upload triage" icon="inbox">
    Separate usable uploads from unclear or irrelevant images before the next step.
  </Card>
  <Card title="Document intake" icon="file-text">
    Route likely receipts, forms, or other image types to the right workflow.
  </Card>
  <Card title="Human review routing" icon="shield-check">

## Catalog photo checks

```python
from imagejev import ImageJev

jev = ImageJev()
result = jev.decide(
    image="listing.jpg",
    decision="Is this photo ready for a product listing?",
    schema={
        "type": "choice",
        "options": {
            "ready": "clear, focused, well-lit product photo",
            "needs_review": "blurry, dark, cluttered, or damaged photo",
            "other": "not a product photo",
        },
    },
)

if result.choice == "ready" and result.confidence >= 0.85:
    approve_listing()
else:
    send_to_review()
```

## Split complex checks

Instead of one broad question, ask focused questions and combine them in your own code:

```python
focus = jev.decide(
    image="listing.jpg",
    decision="Is the product in focus?",
    schema={
        "type": "choice",
        "options": {
            "yes": "sharp edges and visible product details",
            "no": "soft focus, motion blur, or unreadable details",
        },
    },
)

background = jev.decide(
    image="listing.jpg",
    decision="Is the background suitable for a listing?",
    schema={
        "type": "choice",
        "options": {
            "yes": "clean, simple, non-distracting background",
            "no": "cluttered, distracting, or inappropriate background",
        },
    },
)
```

## Review routing

Confidence can help route work, but choose a threshold with examples from your own data:

```python
if result.confidence >= 0.85 and result.choice != "other":
    continue_workflow()
else:
    send_to_review()
```

## Keep expectations clear

- Results are structured, but they are not a guarantee of correctness.
- Include an `other` option when images can fall outside the question.
- Validate thresholds on representative examples from your task.
- Do not use the examples here as accuracy or cost guarantees.
