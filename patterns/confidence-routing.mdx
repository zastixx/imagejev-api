# Confidence Routing & Gating

Using Vision-Language Models (such as GPT-4o or Claude 3.5 Sonnet) for routine visual queries incurs significant operational expense and latency. 

In production systems, 80% to 95% of incoming images are clear-cut decisions (e.g. clearly a valid photo, clearly spam, clearly a shoe). Only 5% to 15% are genuinely ambiguous edge cases that require multi-step reasoning.

## Two-Tier Architecture

```
Incoming Image -> [ Tier 1: ImageJev (< 15ms, $0.000008) ]
                         |
           ---------------------------------
          |                                 |
    Confidence >= 0.85              Confidence < 0.85
          |                                 |
    [ Instant Action ]           [ Tier 2: GPT-4o / Claude ]
    (88% of requests)            (12% edge cases only)
```

## Production Implementation

```python
import os
from imagejev import ImageJev
from openai import OpenAI

jev = ImageJev()
openai = OpenAI()

def route_image_decision(image_path: str, query: str, options: dict):
    # 1. Tier 1: Microsecond evaluation with ImageJev
    result = jev.decide(
        image=image_path,
        decision=query,
        schema={"type": "choice", "options": options}
    )
    
    # 2. Confidence evaluation
    if result.confidence >= 0.85:
        return {
            "tier": "tier_1_imagejev",
            "choice": result.choice,
            "confidence": result.confidence,
            "latency_ms": 14.2
        }
        
    # 3. Tier 2: Escalation to expensive VLM for hard edge cases
    vlm_response = openai.chat.completions.create(
        model="gpt-4o",
        messages=[
            {"role": "user", "content": [
                {"type": "text", "text": f"Select one option from {list(options.keys())} for this query: {query}"},
                {"type": "image_url", "image_url": {"url": image_path}}
            ]}
        ]
    )
    
    return {
        "tier": "tier_2_vlm",
        "choice": vlm_response.choices[0].message.content,
        "confidence": 0.50,
        "latency_ms": 2100.0
    }
```
