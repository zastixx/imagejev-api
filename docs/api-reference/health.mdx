`GET /health`

Returns the service status, version, current concurrency, and configured limits.

<Note>
This endpoint is public by design. Load balancers, Kubernetes probes, and uptime monitors can call it freely without an API key.
</Note>

## Request

No parameters or authentication are required.

<CodeGroup>
```bash cURL
curl -X GET "https://api.imagejev.dev/health"
```

```python Python
import requests

data = requests.get("https://api.imagejev.dev/health").json()

print(f"Status: {data['status']}")
print(f"In flight: {data['concurrency']['in_flight']} / {data['concurrency']['max_concurrent']}")
```

```typescript TypeScript
const response = await fetch("https://api.imagejev.dev/health");
const health = await response.json();

console.log(health.status, health.limits);
```
</CodeGroup>

## Response

A healthy service returns `200 OK`:

```json
{
  "status": "ok",
  "service": "imagejev",
  "version": "0.2.0",
  "concurrency": {
    "in_flight": 1,
    "max_concurrent": 4
  },
  "rate_limiter": {
    "enabled": true,
    "default_rpm": 60
  },
  "limits": {
    "max_batch_size": 50,
    "max_questions": 25,
    "max_image_mb": 10
  }
}
```

### Response fields

| Field | Type | Description |
| --- | --- | --- |
| `status` | `string` | `"ok"` means the service is ready for requests. |
| `service` | `string` | Service name, always `"imagejev"`. |
| `version` | `string` | Running server version. |
| `concurrency.in_flight` | `integer` | Requests currently being processed. |
| `concurrency.max_concurrent` | `integer` | Maximum concurrent requests before queueing or a `503` response. |
| `rate_limiter.enabled` | `boolean` | Whether per-client rate limiting is active. |
| `rate_limiter.default_rpm` | `integer` | Default requests per minute for each client. |
| `limits.max_batch_size` | `integer` | Maximum images per [`/decide_batch`](/api-reference/decide-batch) request. |
| `limits.max_questions` | `integer` | Maximum questions per [`/v1/systemone`](/api-reference/systemone) request. |
| `limits.max_image_mb` | `integer` | Maximum image size in megabytes. |
