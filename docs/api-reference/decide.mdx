`POST /decide`

Evaluates one image against one decision schema and returns typed probabilities and confidence metrics.

## Request

### Headers

| Header | Type | Required | Description |
| --- | --- | --- | --- |
| `Content-Type` | `string` | Yes | Must be `application/json`. |
| `X-API-Key` | `string` | Conditional | Required in `production` and `staging` environments. |

### Body parameters

| Parameter | Type | Required | Limit | Description |
| --- | --- | --- | --- | --- |
| `image` | `string` | Yes | 10 MB | A public image URL (`https://...`), a Base64 string, or a data URI (`data:image/jpeg;base64,...`). |
| `decision` | `string` | Yes | 1,000 characters | The visual question or statement to evaluate. |
| `schema` | `object` | Yes | Valid schema | A Choice, Score, or Noul definition. |

## Schemas

<Tabs>
  <Tab title="Choice">
    Selects the best category from two or more options. See [Choice](/primitives/choice).

    ```json
    {
      "type": "choice",
      "options": {
        "electronics": "a smartphone, laptop, camera, or gadget",
        "apparel": "clothing, shoes, bags, or garments",
        "home": "furniture, decor, kitchenware, or lighting",
        "other": "an item that does not match the categories above"
      },
      "allow_none": false,
      "relevance_threshold": 0.20
    }
    ```
  </Tab>
  <Tab title="Score">
    Rates an image on an ordered scale of 2 to 10 levels. See [Score](/primitives/score).

    ```json
    {
      "type": "score",
      "levels": [
        "dark, blurry, out-of-focus, or heavily distorted",
        "acceptable clarity but sub-optimal lighting or slight motion blur",
        "sharp, well-lit, clear product details",
        "studio-grade professional lighting, perfect isolation and sharpness"
      ]
    }
    ```
  </Tab>
  <Tab title="Noul">
    Returns the probability that a statement is true. See [Noul](/primitives/noul).

    ```json
    {
      "type": "noul",
      "true": "a clearly visible handwritten signature is present",
      "false": "no signature or writing is visible"
    }
    ```
  </Tab>
</Tabs>

## Example request

<CodeGroup>
```bash cURL
curl -X POST "https://api.imagejev.dev/decide" \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "image": "https://images.unsplash.com/photo-1542291026-7eec264c27ff",
    "decision": "Identify the primary item in this photo",
    "schema": {
      "type": "choice",
      "options": {
        "sneaker": "athletic running shoe or sneaker",
        "apparel": "t-shirt, jacket, or pants",
        "accessory": "watch, sunglasses, or hat",
        "other": "none of the above"
      }
    }
  }'
```

```python Python SDK
from imagejev import ImageJevClient

client = ImageJevClient(base_url="https://api.imagejev.dev", api_key="YOUR_API_KEY")

result = client.decide(
    image="https://images.unsplash.com/photo-1542291026-7eec264c27ff",
    decision="Identify the primary item in this photo",
    schema={
        "type": "choice",
        "options": {
            "sneaker": "athletic running shoe or sneaker",
            "apparel": "t-shirt, jacket, or pants",
            "accessory": "watch, sunglasses, or hat",
            "other": "none of the above",
        },
    },
)

print(result.choice)         # "sneaker"
print(result.confidence)     # 0.985
print(result.probabilities)  # {"sneaker": 0.985, "apparel": 0.008, ...}
```

```typescript TypeScript
const response = await fetch("https://api.imagejev.dev/decide", {
  method: "POST",
  headers: {
    "X-API-Key": "YOUR_API_KEY",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    image: "https://images.unsplash.com/photo-1542291026-7eec264c27ff",
    decision: "Identify the primary item in this photo",
    schema: {
      type: "choice",
      options: {
        sneaker: "athletic running shoe or sneaker",
        apparel: "t-shirt, jacket, or pants",
        accessory: "watch, sunglasses, or hat",
        other: "none of the above",
      },
    },
  }),
});

const data = await response.json();
console.log(data.choice, data.confidence);
```

### Response fields

| Field | Type | Schemas | Description |
| --- | --- | --- | --- |
| `choice` | `string` or `null` | Choice | The selected option key. `null` when the image is out of domain and `allow_none` is `true`. |
| `probability` | `float` | Choice, Score, Noul | Primary probability, from 0.0 to 1.0. |
| `confidence` | `float` | Choice, Score | How concentrated the probability distribution is, computed from its entropy. See [Confidence](/concepts/confidence). |
| `is_relevant` | `boolean` | Choice | `true` when the highest similarity to the options exceeds `relevance_threshold`. |
| `relevance` | `float` | Choice | The highest raw similarity score between the image and the options. |
| `score` | `float` | Score | Weighted value across the ordered levels. |
| `dispersion` | `float` | Score | Probability mass outside the peak level and its immediate neighbors. High values signal an ambiguous or split result. |
| `legend` | `object` | Score | Maps each level index to its description. |
| `probabilities` | `object` | Choice, Score | Probability for every option or level. |

For error responses, see the [API overview](/api-reference/overview#http-status-codes).
