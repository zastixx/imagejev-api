`POST /decide_upload`

Uploads a raw image file without Base64 encoding or public hosting. Use it for browser file inputs, mobile uploads, and local scripts. Supported formats are JPEG, PNG, and WebP.

## Request

### Headers

| Header | Type | Required | Description |
| --- | --- | --- | --- |
| `Content-Type` | `string` | Yes | Must be `multipart/form-data`. Most HTTP clients set this for you. |
| `X-API-Key` | `string` | Conditional | Required in `production` and `staging` environments. |

### Form fields

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `file` | `binary` | Yes | None | The image file (JPEG, PNG, or WebP). Maximum 10 MB. |
| `decision` | `string` | No | `"Is this product suitable for listing?"` | The plain-language question or statement. |
| `schema` | `string` (JSON) | No | A default binary choice | A JSON-encoded Choice, Score, or Noul definition. |

<Note>
  `schema` is sent as a JSON string inside the form, not as a nested object.
</Note>

## Example request

<CodeGroup>
```bash cURL
curl -X POST "https://api.imagejev.dev/decide_upload" \
  -H "X-API-Key: YOUR_API_KEY" \
  -F "file=@/path/to/local_receipt.jpg" \
  -F "decision=Is this image an expense receipt or invoice?" \
  -F 'schema={"type": "choice", "options": {"receipt": "printed paper receipt or bill", "other": "random document, photo, or object"}}'
```

```python Python
import json
import requests

url = "https://api.imagejev.dev/decide_upload"
headers = {"X-API-Key": "YOUR_API_KEY"}

schema = {
    "type": "score",
    "levels": ["blurry", "fair", "sharp", "studio"],
}

with open("local_photo.jpg", "rb") as f:
    response = requests.post(
        url,
        headers=headers,
        files={"file": ("photo.jpg", f, "image/jpeg")},
        data={
            "decision": "Rate visual clarity and sharpness",
            "schema": json.dumps(schema),
        },
    )

print(response.json())
```

```typescript Browser
const formData = new FormData();
formData.append("file", fileInputElement.files[0]);
formData.append("decision", "Is this image an expense receipt?");
formData.append(
  "schema",
  JSON.stringify({
    type: "choice",
    options: {
      receipt: "printed paper receipt or bill",
      other: "random document or photo",
    },
  })
);

const response = await fetch("https://api.imagejev.dev/decide_upload", {
  method: "POST",
  headers: { "X-API-Key": "YOUR_API_KEY" },
  body: formData,
});

const data = await response.json();
console.log(data.choice, data.confidence);
```
</CodeGroup>

<Warning>
  The browser example exposes your API key to anyone who opens the page. In production, send uploads through your own backend.
</Warning>

## Response

A successful request returns `200 OK`. The fields match [`POST /decide`](/api-reference/decide) for the schema type you used.

```json
{
  "choice": "receipt",
  "probability": 0.9912,
  "confidence": 0.9824,
  "is_relevant": true,
  "relevance": 0.341,
  "probabilities": {
    "receipt": 0.9912,
    "other": 0.0088
  }
}
```

## Errors

| Code | When |
| --- | --- |
| `413 Payload Too Large` | The file exceeds the size limit (default 10 MB). |
| `422 Unprocessable Entity` | `schema` is not valid JSON, or it breaks schema rules. |

See the [API overview](/api-reference/overview#http-status-codes) for all status codes.
