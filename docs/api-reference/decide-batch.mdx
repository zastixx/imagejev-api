# Batch Decisions (`POST /decide_batch`)

Evaluates a single decision schema across an array of up to 50 images simultaneously. 

Because text criteria vectors are embedded once and multiplied against the batch image matrix in a single BLAS GEMM operation, batch inference is dramatically faster than looping individual calls.

## Request

### Headers

| Header | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `Content-Type` | `string` | **Yes** | Must be `application/json`. |
| `X-API-Key` | `string` | Conditional | Required when operating in `production` or `staging` environments. |

### Body Parameters

| Parameter | Type | Required | Constraints | Description |
| :--- | :--- | :--- | :--- | :--- |
| `images` | `string[]` | **Yes** | 1 to 50 items | List of image URLs, Base64 strings, or data URIs. |
| `decision` | `string` | **Yes** | Max 1,000 chars | Decision question or evaluation criteria. |
| `schema` | `object` | **Yes** | Valid schema | Choice, Score, or Noul schema definition applied to every image. |

---

## Constraints & Limits

- **Maximum batch size**: `50` images per request. Requests with 0 or > 50 items return `HTTP 400 Bad Request`.
- **Order preservation**: The returned array matches the exact 0-indexed order of the input `images` list.
- **Dedicated Rate Limit**: Controlled by `IMAGEJEV_BATCH_RATE_LIMIT_PER_MINUTE` (default: 15 batch requests/min).

## Code Examples

<CodeGroup>
```bash cURL
curl -X POST "https://api.imagejev.dev/decide_batch" \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "images": [
      "https://example.com/item1.jpg",
      "https://example.com/item2.jpg",
      "https://example.com/item3.jpg"
    ],
    "decision": "Is this product photo acceptable for catalog listing?",
    "schema": {
      "type": "choice",
      "options": {
        "pass": "clean, well-lit, isolated product photo",
        "fail": "dark, blurry, watermarked, or damaged photo"
      }
    }
  }'
```

```python Python (SDK)
from imagejev import ImageJevClient

client = ImageJevClient(base_url="https://api.imagejev.dev", api_key="YOUR_API_KEY")

results = client.decide_batch(
    images=[
        "https://example.com/item1.jpg",
        "https://example.com/item2.jpg",
        "https://example.com/item3.jpg"
    ],
    decision="Is this product photo acceptable for catalog listing?",
    schema={
        "type": "choice",
        "options": {
            "pass": "clean, well-lit, isolated product photo",
            "fail": "dark, blurry, watermarked, or damaged photo"
        }
    }
)

for idx, res in enumerate(results):
    print(f"Image {idx}: {res.choice} (confidence: {res.confidence:.3f})")
```

```typescript TypeScript / Fetch
const response = await fetch("https://api.imagejev.dev/decide_batch", {
  method: "POST",
  headers: {
    "X-API-Key": "YOUR_API_KEY",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    images: [
      "https://example.com/item1.jpg",
      "https://example.com/item2.jpg"
    ],
    decision: "Is this product photo acceptable for catalog listing?",
    schema: {
      type: "choice",
      options: {
        pass: "clean, well-lit, isolated product photo",
        fail: "dark, blurry, watermarked, or damaged photo"
      }
    }
  })
});

const data = await response.json();
console.log(`Evaluated ${data.length} images.`);
```
</CodeGroup>

## Response (`200 OK`)

Returns a JSON array of result objects corresponding 1-to-1 with the input images:

```json

  {
    "choice": "pass",
    "probability": 0.974,
    "confidence": 0.948,
    "is_relevant": true,
    "relevance": 0.318,
    "probabilities": {
      "pass": 0.974,
      "fail": 0.026
    }
  },
  {
    "choice": "fail",
    "probability": 0.892,
    "confidence": 0.784,
    "is_relevant": true,
    "relevance": 0.284,
    "probabilities": {
      "pass": 0.108,
      "fail": 0.892
    }
  }
]
```
