`POST /decide_batch`

Evaluates one decision schema across up to 50 images. The decision criteria are processed once for the whole batch, which is faster than sending a separate request for each image.

## Request

### Headers

| Header | Type | Required | Description |
| --- | --- | --- | --- |
| `Content-Type` | `string` | Yes | Must be `application/json`. |
| `X-API-Key` | `string` | Conditional | Required in `production` and `staging` environments. |

### Body parameters

| Parameter | Type | Required | Limit | Description |
| --- | --- | --- | --- | --- |
| `images` | `string[]` | Yes | 1 to 50 items | Image URLs, Base64 strings, or data URIs. |
| `decision` | `string` | Yes | 1,000 characters | The question or criteria to evaluate. |
| `schema` | `object` | Yes | Valid schema | A Choice, Score, or Noul definition applied to every image. |

## Limits

- **Batch size:** 1 to 50 images. An empty list or more than 50 images returns `400 Bad Request`.
- **Order:** The response array matches the order of the `images` list, starting at index 0.
- **Rate limit:** Batch requests have their own limit, 15 per minute by default. It is set by `IMAGEJEV_BATCH_RATE_LIMIT_PER_MINUTE` on self-hosted deployments.

## Example request

<CodeGroup>
```bash cURL
curl -X POST "https://api.imagejev.dev/decide_batch" \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "images": [
      "https://example.com/item1.jpg",
      "https://example.com/item2.jpg",
      "https://example.com/item3.jpg"
    ],
    "decision": "Is this product photo acceptable for catalog listing?",
    "schema": {
      "type": "choice",
      "options": {
        "pass": "clean, well-lit, isolated product photo",
        "fail": "dark, blurry, watermarked, or damaged photo"
      }
    }
  }'
```

```python Python SDK
from imagejev import ImageJevClient

client = ImageJevClient(base_url="https://api.imagejev.dev", api_key="YOUR_API_KEY")

results = client.decide_batch(
    images=[
        "https://example.com/item1.jpg",
        "https://example.com/item2.jpg",
        "https://example.com/item3.jpg",
    ],
    decision="Is this product photo acceptable for catalog listing?",
    schema={
        "type": "choice",
        "options": {
            "pass": "clean, well-lit, isolated product photo",
            "fail": "dark, blurry, watermarked, or damaged photo",
        },
    },
)

for idx, res in enumerate(results):
    print(f"Image {idx}: {res.choice} (confidence: {res.confidence:.3f})")
```

```typescript TypeScript
const response = await fetch("https://api.imagejev.dev/decide_batch", {
  method: "POST",
  headers: {
    "X-API-Key": "YOUR_API_KEY",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    images: [
      "https://example.com/item1.jpg",
      "https://example.com/item2.jpg",
    ],
    decision: "Is this product photo acceptable for catalog listing?",
    schema: {
      type: "choice",
      options: {
        pass: "clean, well-lit, isolated product photo",
        fail: "dark, blurry, watermarked, or damaged photo",
      },
    },
  }),
});

const data = await response.json();
console.log(`Evaluated ${data.length} images.`);
```
</CodeGroup>

## Response

A successful request returns `200 OK` with a JSON array. Each item matches the result of [`POST /decide`](/api-reference/decide) for the same schema type, in the same order as `images`.

```json
[
  {
    "choice": "pass",
    "probability": 0.974,
    "confidence": 0.948,
    "is_relevant": true,
    "relevance": 0.318,
    "probabilities": { "pass": 0.974, "fail": 0.026 }
  },
  {
    "choice": "fail",
    "probability": 0.892,
    "confidence": 0.784,
    "is_relevant": true,
    "relevance": 0.284,
    "probabilities": { "pass": 0.108, "fail": 0.892 }
  }
]
```
