# Quick start

## Requirements

- Python 3.9 or newer
- An image available as a local path, URL, PIL image, or bytes

## Install

```bash
pip install imagejev==0.1.2
```

For the optional FastAPI server:

```bash
pip install "imagejev[server]"
```

## Make a decision

```python
from imagejev import ImageJev

jev = ImageJev()

result = jev.decide(
    image="product-photo.jpg",
    decision="Is this photo suitable for an e-commerce listing?",
    schema={
        "type": "choice",
        "options": {
            "usable": "a clear, well-lit, focused product photo",
            "unusable": "a blurry, dark, damaged, cluttered, or irrelevant photo",
            "other": "an image that does not clearly fit either option",
        },
        "allow_none": True,
        "relevance_threshold": 0.20,
    },
)

print(result.choice)
print(result.confidence)
print(result.probabilities)
```

## Use the result

Treat the result as a signal for your application. For example:

```python
if result.choice == "usable" and result.confidence >= 0.85:
    approve_listing()
else:
    send_to_review()
```

Choose the threshold using examples from your own workflow. Confidence is not a guarantee of correctness.

## Batch decisions

```python
results = jev.decide_batch(
    images=["one.jpg", "two.jpg"],
    decision="Classify this upload",
    schema={
        "type": "choice",
        "options": {
            "usable": "a clear, focused upload",
            "unusable": "a blurry or damaged upload",
            "other": "not an applicable upload",
        },
    },
)
```
