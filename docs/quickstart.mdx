# Quick start

ImageJev provides a high-speed, strictly-typed visual decision API. Send an image URL (or base64) alongside a closed schema, and receive a deterministic decision with well-calibrated confidence in milliseconds.

## 1. Authentication

Every request to the ImageJev API requires a Bearer token or `X-API-Key` header:

```bash
Authorization: Bearer <YOUR_IMAGEJEV_API_KEY>
```

If you don't have an API key yet, [join the early access waitlist](https://imagejev.dev/waitlist) to receive your credentials.

---

## 2. Make Your First Decision

### Option A: cURL / HTTP

```bash
curl -X POST https://api.imagejev.dev/decide \
  -H "Authorization: Bearer $IMAGEJEV_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "image": "https://images.unsplash.com/photo-1542291026-7eec264c27ff",
    "decision": "Evaluate catalog suitability",
    "schema": {
      "type": "choice",
      "options": {
        "pass": "clean, focused, professional catalog photo",
        "fail": "blurry, dark, damaged, or cluttered photo"
      }
    }
  }'
```

### Option B: Python (`requests`)

```python
import os
import requests

API_KEY = os.getenv("IMAGEJEV_API_KEY", "your_api_key_here")

response = requests.post(
    "https://api.imagejev.dev/decide",
    headers={
        "Authorization": f"Bearer {API_KEY}",
        "Content-Type": "application/json",
    },
    json={
        "image": "https://images.unsplash.com/photo-1542291026-7eec264c27ff",
        "decision": "Evaluate catalog suitability",
        "schema": {
            "type": "choice",
            "options": {
                "pass": "clean, focused, professional catalog photo",
                "fail": "blurry, dark, damaged, or cluttered photo"
            }
        }
    }
)

result = response.json()
print("Choice:", result["choice"])              # -> "pass"
print("Confidence:", result["confidence"])      # -> 0.991
print("Probabilities:", result["probabilities"])# -> {"pass": 0.994, "fail": 0.006}
```

### Option C: TypeScript / JavaScript (`fetch`)

```typescript
const response = await fetch("https://api.imagejev.dev/decide", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${process.env.IMAGEJEV_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    image: "https://images.unsplash.com/photo-1542291026-7eec264c27ff",
    decision: "Evaluate catalog suitability",
    schema: {
      type: "choice",
      options: {
        pass: "clean, focused, professional catalog photo",
        fail: "blurry, dark, damaged, or cluttered photo",
      },
    },
  }),
});

const result = await response.json();
console.log(result.choice);      // "pass"
console.log(result.confidence);  // 0.991
```

## 3. Interpreting the Result

```json
{
  "status": "success",
  "choice": "pass",
  "confidence": 0.991,
  "probability": 0.994,
  "latency_ms": 6.51,
  "calibrated": true,
  "probabilities": {
    "pass": 0.994,
    "fail": 0.006
  }
}
```

Use the result as a deterministic signal in your application:

```python
if result["choice"] == "pass" and result["confidence"] >= 0.95:
    auto_approve_listing()
else:
    route_to_human_moderator()
```
