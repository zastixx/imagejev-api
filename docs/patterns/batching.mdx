# High-Throughput Batching

When processing millions of catalog items or streaming camera frames, invoking single-image inferences leaves GPU tensor cores underutilized.

ImageJev provides native tensor batching via `decide_batch()`.

## Batch Processing

```python
from imagejev import ImageJev

jev = ImageJev()

image_urls = [
    "https://example.com/item1.jpg",
    "https://example.com/item2.jpg",
    # ... hundreds of images
]

schema = {
    "type": "choice",
    "options": {
        "pass": "clear, authentic product photo",
        "reject": "prohibited, copyright-violating, or illegible image"
    }
}

# Evaluates batch concurrently with GPU pipelining
results = jev.decide_batch(
    images=image_urls,
    decision="Content safety & quality check",
    schema=schema,
    batch_size=64
)

for img_url, result in zip(image_urls, results):
    print(f"{img_url} -> {result.choice} ({result.confidence:.3f})")
```
