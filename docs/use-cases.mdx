## 1. E-Commerce Marketplace Quality Assurance

In marketplaces with millions of seller uploads daily, enforcing product photography standards with human review or GPT-4o is cost-prohibitive.

```python
from imagejev import ImageJev

jev = ImageJev()

# Run atomic checks against seller image
sharpness = jev.decide(
    image="listing_image.jpg",
    decision="Is this photo sharp and focused?",
    schema={"type": "choice", "options": {"sharp": "crisp edges and clear details", "blurry": "soft, out of focus, motion blur"}}
)

background = jev.decide(
    image="listing_image.jpg",
    decision="Is the background isolated or cluttered?",
    schema={"type": "choice", "options": {"isolated": "clean white or neutral studio backdrop", "cluttered": "bedroom, carpet, messy background"}}
)

if sharpness.choice == "sharp" and background.choice == "isolated":
    approve_listing()
else:
    flag_for_seller_reupload()
```

## 2. Two-Tier VLM Cost Gating

Rather than paying $0.005 per query for GPT-4o across 100,000 queries/day ($500/day):
1. **Tier 1 (ImageJev)**: Runs on GPU in <15ms. Cost: $0.000008/call.
2. If `confidence >= 0.85`, use the ImageJev decision immediately.
3. If `confidence < 0.85` (borderline ambiguity), route the query to Tier 2 (GPT-4o or Claude 3.5 Sonnet).

**Result**: 85% to 92% of queries exit at Tier 1, slashing overall vision infrastructure costs by 80–90%.
