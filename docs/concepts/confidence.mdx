# Confidence

`choice` and `score` results include a `confidence` value between `0.0` and `1.0`.

Confidence is useful for deciding whether to automate a result or send it for review. It is not a guarantee that the result is correct.

```python
result = jev.decide(
    image="photo.jpg",
    decision="Is this upload ready?",
    schema={
        "type": "choice",
        "options": {
            "ready": "clear and complete upload",
            "review": "unclear or incomplete upload",
            "other": "not an applicable upload",
        },
    },
)

if result.confidence >= 0.85 and result.choice == "ready":
    continue_workflow()
else:
    send_to_review()
```

## Choosing a threshold

There is no universal threshold. Use representative examples from your workflow and measure:

- How often the result is correct.
- How many cases can be automated.
- How many uncertain cases reach review.

## Practical guidance

- Keep an `other` option when an image may be out of scope.
- Use `allow_none` when abstention is preferable to a forced choice.
- Revisit thresholds when your images or business rules change.
