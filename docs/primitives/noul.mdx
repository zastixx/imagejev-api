---
title: "Noul"
description: "Check whether one visual statement applies to an image."
---

Use `noul` for a focused yes-or-no visual check.

```python
from imagejev import ImageJev

jev = ImageJev()
result = jev.decide(
    image="document.jpg",
    decision="Is a signature visible?",
    schema={
        "type": "noul",
        "true": "a visible handwritten signature",
        "false": "no visible handwritten signature",
    },
)

print(result.probability)
```

## Schema

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `type` | `string` | Yes | Must be `"noul"`. |
| `true` | `string` | Yes | Describes what the image looks like when the statement is true. |
| `false` | `string` | Yes | Describes what the image looks like when the statement is false. |

## Result fields

| Field | Description |
| --- | --- |
| `probability` | Probability that the `true` statement applies to the image, from `0.0` to `1.0`. |

## Good uses

- Is a watermark visible?
- Is the subject wearing a helmet?
- Is the image suitable for the next workflow step?

## Tips

- Ask one focused question.
- Describe both sides clearly with `true` and `false`.
- Choose an action threshold using examples from your task.
